# One Legacy

Atualizacoes do modpack One Legacy (Minecraft 1.16.5 + Mine Mine no Mi). O mod "One Legacy Atualizador" de cada jogador le o `manifest.json` daqui ao abrir o jogo.

Os mods de terceiros sao baixados das paginas oficiais (CurseForge); aqui ficam so as configuracoes, o pacote de texturas e os mods do proprio pack.
